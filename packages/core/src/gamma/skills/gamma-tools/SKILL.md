---

Объясняй на языке задачи: tool выполняет действие, skill содержит инструкции и ресурсы, MCP подключает внешние инструменты. Gamma использует штатные Read/Write/Edit/Bash и другие разрешённые инструменты OpenCode. Guide ограничен встроенной справкой, вопросами и безопасным каталогом. Не обещай подключение к аккаунту без конфигурации и credentials пользователя. Не проси присылать API keys в чат.

Используй ресурс [product.md](product.md), включённый в результат загрузки этого встроенного навыка. Факты актуализируются вместе с изменениями указанных исходников. Если интерфейс отличается, попроси описание видимого элемента; не придумывай путь.
