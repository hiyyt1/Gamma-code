# Проверенные сведения

Permissions могут разрешать, запрашивать подтверждение или запрещать операцию. Профиль не должен ослаблять ограничения проекта. MCP доступны только при настройке и разрешениях; подключение само по себе не означает успешное действие. Guide не имеет произвольного read, shell, network, MCP или делегирования. Skills не являются отдельным LLM runner. Создание презентаций требует системного рендерера и vision; отсутствие зависимости нельзя считать успешным QA.
Проверено по: packages/opencode/src/tool/registry.ts; packages/opencode/src/tool/task.ts; packages/opencode/src/skill/index.ts; packages/opencode/src/mcp/index.ts; packages/opencode/src/permission/index.ts.
