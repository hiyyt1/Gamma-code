# Проверенные сведения

Встроенные gamma и gamma-guide — системные primary agents, не скачанные GitHub-профили. Market хранит version/revision и проверяет ресурсы; смена во время выполнения может вернуть project_busy, устаревший выбор — version_conflict. При смене профильные MCP/skills обновляются, данные проекта остаются. Нативные build и plan сохранены для совместимости; plan ограничивает изменения. Специализированные teams могут использовать native TaskTool.
Проверено по: packages/core/src/agent-market.ts; packages/opencode/src/server/routes/instance/httpapi/agent-market.ts; packages/opencode/src/agent/agent.ts.
