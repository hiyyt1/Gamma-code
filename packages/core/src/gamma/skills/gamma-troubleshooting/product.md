# Проверенные сведения

project_busy: дождаться завершения активной задачи. version_conflict: обновить выбор агента. agent_unavailable/integrity_failed: профиль или ресурсы недоступны, администратору проверить поставку. Отказ permissions: объяснить ограничение, не обходить. Ошибка модели/авторизации: проверить выбранный provider в настройках, не публиковать ключи. Недоступный MCP: проверить настройку соответствующего подключения. Ошибки рендера/vision: результат остаётся черновиком. Guide не имеет доступа к приватным runtime-логам и не обещает автоматическую починку.
