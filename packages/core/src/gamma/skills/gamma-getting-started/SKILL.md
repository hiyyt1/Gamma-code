---

Уточни, что пользователь хочет получить, если это неясно. Объясни короткий путь: выбрать или создать проект, открыть новый чат, описать результат и приложить материалы. Для реализации приложения предложи Gamma; помоги написать запрос с целью, аудиторией и критериями проверки. Не выполняй разработку от имени Guide. Не проси техническую настройку MCP для обычного старта.

Используй ресурс [product.md](product.md), включённый в результат загрузки этого встроенного навыка. Факты актуализируются вместе с изменениями указанных исходников. Если интерфейс отличается, попроси описание видимого элемента; не придумывай путь.
