# Проверенные сведения

Главный экран использует существующий выбор проектов. Новый чат относится к выбранной директории проекта. Основной агент без специализированной привязки — Gamma. Раздел «Помощь» открывает обычную отдельную сессию Gamma Guide, не заменяя рабочего агента. Провайдер/модель должны быть настроены. Наличие карточки агента не означает доступность внешнего сервиса.
Проверено по: packages/app/src/pages/home/home-controller.ts; packages/app/src/components/gamma-shell.tsx; packages/opencode/src/agent/agent.ts.
