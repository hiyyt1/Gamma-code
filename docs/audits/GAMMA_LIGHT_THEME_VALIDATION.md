# Gamma: единая светлая тема

12 октября 2026. Исправление визуального дефекта F-01 из [аудита](GAMMA_FRONTEND_INCIDENT.md). Новое требование пользователя — единственная светлая тема — заменяет прежнюю рекомендацию поддерживать обе палитры.

## Изменения

- `packages/app/index.html`: светлые атрибуты и `color-scheme: only light` присутствуют в исходном HTML; meta color-scheme также ограничивает оформление светлой схемой. Версия URL preload изменена, чтобы новый HTML не использовал прежний кешированный переключатель.
- `packages/app/public/oc-theme-preload.js`: до запуска module entry устанавливает OC-2 Light, мигрирует `opencode-theme-id`/`opencode-color-scheme`, удаляет оба старых CSS-кеша. Не читает системную тему и не вставляет пользовательский cached CSS. Ошибка доступа к storage не мешает установке палитры.
- `packages/app/src/app.tsx` и `packages/ui/src/theme/context.tsx`: Gamma использует режим `lightOnly`. Он синхронно применяет **обе** группы токенов, legacy и V2, из существующей OC-2 Light. Нет подписки на системную тему, загрузки альтернативных тем или предпросмотра dark. Записи старых вкладок в ключи темы нормализуются. Остальные пользовательские настройки, история и IndexedDB не удаляются.
- `packages/ui/src/styles/theme.css`: OS-dark fallback исключает корень с явно заданной светлой схемой. Это закрывает промежуток между загрузкой CSS и монтированием ThemeProvider.
- Из обеих версий настроек удалены только выбор схемы/палитры и обслуживающая их логика. Из legacy command registry удалены выбор, предпросмотр и горячие клавиши тем. Настройки шрифтов и прочие функциональные настройки сохранены.
- Общая библиотека UI сохраняет обычный ThemeProvider для других потребителей; Gamma всегда включает фиксированный режим. Это не изменение OpenCode runtime или его терминальных тем.
- Общий E2E mock теперь отвечает на `/auth/session`; отдельный fixture моделирует Gamma projects/files/knowledge/catalog. Авторизация production не менялась.

`gamma.css`, размеры, layout, компоненты навигации, фиолетовые акценты и анимации не изменены. Конфликт фиксированных светлых поверхностей Gamma с динамическими тёмными токенами устранён на уровне выбора палитры, а не дополнительным перекрашиванием отдельных кнопок.

## Проверки

Итог: **16/16 Playwright, 21/21 unit**, проверки типов `app`, `ui`, `e2e` и форматирование изменённых файлов прошли. Последняя production-сборка завершилась за 17,78 s; предупреждение Vite о крупных chunks осталось, оптимизация сборки не входила в задачу. [Результаты и контраст](evidence/gamma-light-2026-10-12/summary.json), [полный Playwright JSON](evidence/gamma-light-2026-10-12/gamma-light-report.json), [лог](evidence/gamma-light-2026-10-12/gamma-light-final.log), [отпечатки файлов](evidence/gamma-light-2026-10-12/sha256.json).

Реальный frontend проверяется через Vite production build и Playwright Chromium. Backend-ответы — управляемые fixtures; production, OpenCode и LLM не запускались. Preview использует отдельный порт 4518, сборка — `/tmp/gamma-light-build`.

Матрица проверок основных страниц:

Во всех строках выполняются navigation, перезагрузка и смена OS scheme после mount. Проверяется, что тема остаётся светлой, storage нормализован, а старые CSS-кеши отсутствуют.

Покрыты главная/«Мои проекты», переход по карточке проекта в чат, Markdown/code, ввод текста и enabled/disabled отправки, файловая панель и содержимое файла, новый чат, форма проекта, каталог/поиск агентов и подробности, база знаний и диалог пространства, меню профиля и настройки. Проверены hover/focus кнопки «Новый чат», ввод в диалоги, отмена и закрытие. Действия выполняются обычными Playwright actions, без принудительного `force`-клика.

Отдельные сценарии:

- До исполнения основного JS, при OS dark, с сохранённой тёмной темой и при недоступном storage: HTML, browser color scheme, фон и legacy text token остаются светлыми.
- Вторая вкладка записывает старую тему: открытая Gamma не меняет палитру, storage возвращается к light/oc-2.
- Mobile: чтение файла, закрытие файловой панели, ввод в освобождённую область чата, открытие/закрытие sidebar, настройки и форма проекта.
- Управляемая задержка загрузки файла на двух viewport: loading виден, кнопка возврата остаётся доступной, после ответа появляется файл. Это проверка состояния UI, не benchmark.

## Сохранение дизайна

20 эталонных снимков сняты на **прежней** светлой production-сборке `/tmp/gamma-performance-audit-build` из аудита, до применения исправления. Два новых эталона настроек фиксируют намеренное удаление строк темы. [Снимки](../../packages/app/e2e/gamma-light/snapshots) входят в тестовый набор.

Сравнение основных экранов допускает до 0,2% отличающихся пикселей; отдельные mobile-сценарии используют стандартное строгое сравнение Playwright. Настройки теста не маскируют кнопки/текст. Только в fixture основных визуальных сценариев отключён видеотост знакомства со вкладками, чтобы движение видео не влияло на сравнение; production-анимации не менялись.

Измеренный контраст ключевых элементов одинаков при проверенных OS/storage:

| Элемент | Контраст |
| --- | ---: |
| «Новый чат», обычное и hover-состояние | 18,10:1 |
| Текст composer | 18,10:1 |
| Текст ответа | 12,61:1 |
| Кнопка «Использовать» в каталоге | 4,80:1 |
| Поле диалога базы знаний | 12,08:1 |

Расчёт использует computed RGB и композицию прозрачных фонов предков. Проверяемые элементы должны иметь контраст ≥4,5:1. Это не полная WCAG-сертификация всех текстов, изображений, disabled-состояний и стороннего содержимого.

## Повторный запуск

Из `packages/app`:

```bash
SENTRY_AUTH_TOKEN= VITE_OPENCODE_SERVER_HOST=127.0.0.1 VITE_OPENCODE_SERVER_PORT=4518 bun run build --outDir /tmp/gamma-light-build
bunx --no-install playwright test --config e2e/gamma-light/playwright.config.ts
bun test --conditions=solid --preload ./happydom.ts ./src/theme-preload.test.ts ./src/context/settings.test.ts
bun typecheck
bun run typecheck:e2e
```

Из `packages/ui`: `bun typecheck`.

Обычный запуск сравнивает сохранённые снимки и не обновляет их. JSON-отчёт находится в `/tmp/gamma-light-report.json`, результаты и снимки loading — в `/tmp/gamma-light-results`. `GAMMA_LIGHT_BASELINE=1` предназначен только для контролируемого снятия эталонов с прежней сборки, не для проверки исправления.

## Ограничения и оставшиеся особенности

В проверенной матрице цветовых дефектов и некликабельности из-за невидимых элементов не обнаружено. Console/pageerror в сценариях обхода основных страниц отсутствуют. Существующая узкая компоновка настроек на 390 px сохранена; содержимое доступно прокруткой. Файловая панель и открытая мобильная навигация намеренно перекрывают часть страницы и закрываются штатными кнопками — эти действия проверены.

Не проверялись Firefox/Safari, все возможные пользовательские документы и расширения, принудительно подменяющие CSS. Заблокированный storage проверен для **начального оформления**, а не как гарантия работоспособности всех остальных подсистем приложения без хранилища. Fixtures не подтверждают доступность настоящего backend или успешное выполнение агента.

SSE, streaming, производительность, backend, permissions, Auto mode и агенты не исправлялись. Production не изменялся.
