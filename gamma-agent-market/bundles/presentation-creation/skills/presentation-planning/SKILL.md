# Planning
Read the user brief and ingest attached materials first. Infer language, audience and requested count; ask only for missing facts that materially change the argument. Do not ask the user to choose libraries or approve each slide.
Write sources/brief.json: audience, decision requested, objective, constraints, count, route, evidence and unknowns. Write sources/story.json as ordered action titles with takeaway, evidence, composition intent and speaker notes. The requested count is exact unless the user permits otherwise.
Choose pptagent for new narrative decks, data for quantitative work, edit for modifying an existing PPTX. A redesign is a new output with a fact inventory against the original; a one-slide edit must preserve other slides.
Keep user originals, generated sources and data separate. A clear title sequence should communicate the whole argument without body text. Never invent results, customers or forecasts. Label scenarios and assumptions.
Load [outline schema](references/outline.md) before authoring. Do not overwrite sources after finalization; revise them in the same workspace and keep the exported history.
