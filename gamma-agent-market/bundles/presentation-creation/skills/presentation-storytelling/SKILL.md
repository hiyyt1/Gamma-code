# Storytelling
Work from sources/brief.json and researcher evidence. Produce sources/story.json, with one claim and its support per slide. Keep facts traceable to supplied files/pages/cells; flag unverified claims.
For leadership: current problem → stakes → alternatives → recommendation → economics with sourced assumptions → risks → accountable rollout → requested decision.
For sales: customer's situation → consequence → relevant value → evidence → solution → implementation → offer → next step. Avoid unsupported promises.
For investors: problem → insight → solution → market evidence → traction → business model → go-to-market → team → sourced financial assumptions → ask. Missing traction remains unknown.
For training: learning objective → worked example → explanation → practice → feedback → recap. For conference talks, build an argument through concrete examples rather than a report outline.
Use evidence-led action titles. Move explanatory detail into notes. A sequence, comparison, chart or diagram should replace a list when relationships carry the message. Do not impose the same composition on every slide.
