# Design
Read sources/story.json and the brand findings. Choose a visual direction, not a rigid template. Use meaning to choose layouts; never decorate every slide with identical cards or icons.
Editorial Minimal: strong typography, asymmetric editorial grids, generous space and evidence-led image crops.
Business Consulting: action titles, analytical charts, comparisons, matrices and explicit recommendations.
Tech Premium: precise geometric hierarchy, restrained dark/light contrast and clear technical diagrams; avoid arbitrary gradients.
Visual Storytelling: meaningful photography/illustration, sequences and visual metaphors that support a claim; use only provided/licensed assets.
Corporate: reuse inspected brand fonts/colors, canvas dimensions and master style. Do not invent brand guidelines.
Data-driven: chart-first layouts, clear units and periods, direct labels, sources, uncertainty and restrained color.
Alternate title/statement, comparison, process, timeline, chart, image and synthesis compositions as the content requires. Typical heading 30–44pt; body 22–28pt; rarely below 18pt. Avoid more than one main idea or dense paragraphs. Leave 0.4–0.6 inch margins.
For HTML follow pptagent's HTML contract; all text remains native. Avoid nested styling/gradients unsupported by the converter. Use real images only when meaningful. Native structured elements can make editable arrows, process nodes, diagrams and charts.
Run actual export/render, then review. A visually balanced HTML source does not guarantee PPTX font metrics. Fix source typography or geometry rather than flattening a slide.
