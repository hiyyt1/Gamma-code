# Gamma HTML export contract (PPTAgent adaptation)
Canvas: body margin:0; width:1280px; height:720px; position:relative; explicit solid background-color. Use inline <style> for local static CSS. No external URLs, scripts, iframes, SVG, canvas, nested elements, transforms, shadows or gradients.
Each direct body element MUST carry data-pptx="text|shape|image" and explicit absolute x/y/width/height (CSS left/top). Use standalone p/h1 text nodes, div for shapes (data-shape="rect|ellipse|line|chevron|roundRect|rightArrow"), img for PNG/JPEG with local src relative to the HTML file. Native typography is uniform per text object. No padding/borders/background on text; use a separate native shape behind it. The first CSS font-family must exactly match outline.font; use Liberation Sans unless an installed corporate font is required.
Example:
```html
<!doctype html><html><head><title>A focused recommendation</title><meta name="takeaway" content="Start with a measurable pilot"><style>body{margin:0;width:1280px;height:720px;position:relative;background:#fff;font-family:"Liberation Sans"}p{position:absolute;margin:0}</style></head><body><p data-pptx="text" style="left:64px;top:64px;width:1120px;height:96px;font-size:48px;color:#172b3a;font-weight:700">Start with a measurable pilot</p><div data-pptx="shape" style="position:absolute;left:64px;top:220px;width:8px;height:280px;background:#16697a"></div><p data-pptx="text" style="left:112px;top:230px;width:920px;height:180px;font-size:32px;color:#172b3a">Define baseline, owner and exit criteria before scaling.</p></body></html>
```
All file paths must stay inside the presentation workspace. Images are loaded by the exporter, not fetched by the browser. Unsupported styling fails rather than being silently flattened. Run build with ALL ordered HTML paths matching the slide count in outline.json; compiled native outline is retained in history/outline-N.json. For charts/tables use the structured data route, or combine them through precise office-kit edits only when supported.
