---
name: 1c-environment
description: Проверка локальных зависимостей разработки 1С и выбор доступного режима без имитации запуска платформы.
---

Перед операциями, требующими платформы, выполни:

```sh
"{{PYTHON}}" "{{SKILLS_ROOT}}/1c-environment/scripts/check.py"
```

Скрипт проверяет Python/lxml, наличие Java, файла GAMMA_BSL_JAR и исполняемого файла платформы. Путь к платформе можно передать через GAMMA_1C_PLATFORM; иначе проверяется PATH (1cv8, 1cv8c). Наличие файла не подтверждает лицензию, доступность базы или работоспособность платформы. MCP проверяется отдельно штатным механизмом Gamma; этот скрипт не объявляет его подключённым.

Если platform.executable отсутствует, прямо сообщи: «Платформа 1С не обнаружена; сборка бинарных CF/CFE/EPF/ERF, запуск и проверка в информационной базе недоступны». Предложи разработку и статическую проверку исходников. Ничего не устанавливай и не имитируй бизнес-тесты. Если файл обнаружен, запроси явно выбранную тестовую базу перед операциями с ней и проверь фактический результат запуска; обнаружение файла само по себе недостаточно.
